# Decisions

Accepted decisions that define the Phase 0 foundation:

- [Elementor-First Classic Theme and Separate Core Plugin](elementor-first-class-theme.md) — keep the theme focused on presentation and put reusable business behavior in the companion plugin.
- [Elementor-Editable Global Header](elementor-editable-header.md) — support Elementor Pro Theme Builder and provide an Elementor Free saved-template header slot.
- [Local Elementor Editor Dependencies](local-elementor-editor-assets.md) — pin the existing Ace dependency locally and document the remaining loading uncertainty.
- [Iranian Toman Price Display](iranian-toman-display.md) — retain WooCommerce's IRR currency code while displaying and entering values in toman units.
